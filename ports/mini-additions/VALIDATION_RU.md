# Проверка MINI additions 1.4.0-port.1 — NeoForge 1.21.1

Неофициальный порт, RC1. 11 октября 2026.

Проверено в GitHub Actions:
https://github.com/Miniezi/Proverka/actions/runs/38138256793
Исходники:
https://github.com/Miniezi/Proverka/tree/mini-additions-1.21.1/ports/mini-additions

Среда: Java 21, NeoForge 21.1.256, Minecraft 1.21.1, Spore 2.2.0j.
Второй запуск дополнительно с Farmer's Delight 1.3.4.

Результат:
- Сервер запустился и штатно остановился в обоих вариантах.
- Загружены все 69 функций MINI additions.
- Загружены все 16 основных рецептов.
- С Farmer's Delight загружены все 157 рецептов (16 + 141).
- Проверены ключевые достижения, включая цепочку рейдов.
- Защитник из структуры ff_1 успешно прочитан и сохраняет эффект сопротивления.
- На реальном экземпляре протомозга инициализированы таймеры: 884000 и 32.
- JAR содержит сам аддон, тестовый Java-мод в него НЕ включён.

Известные ограничения:
- Клиент, мультиплеер с игроками, полный цикл рейдов и полная пользовательская сборка не прогонялись.
- Совместимости Create, Better Combat, Incendium, Wither Storm, Touhou Little Maid не проверялись в игре.
- В оригинальном Spore 2.2.0j есть пять рецептов для необязательных модов без условий загрузки.
  Без этих модов сервер пишет ошибки именно этих рецептов и продолжает запуск.
  Они присутствуют в исходном JAR Spore, в порт MINI additions не включены.
- Ледяной заряд сохраняет тяжёлую механику оригинала: огромные fill/forceload-команды,
  изменение лимита обработки блоков и forceload remove all. Возможны длительные зависания;
  он также снимает принудительную загрузку чужих чанков. Не тестировать его в основном мире.

Установка:
1. Нужны Minecraft 1.21.1, NeoForge и Spore для 1.21.1 (проверено со Spore 2.2.0j).
2. Скопировать только spore_mini_additions-1.4.0-port.1-neoforge-1.21.1.jar из архива в mods.
3. Удалить старый Forge-вариант MINI additions, если установлен.
4. Не совмещать со Spore Inquisition: это ограничение автора оригинала.
5. Create и Farmer's Delight ставить не обязательно. Для рецептов Farmer's Delight проверена версия 1.3.4.
6. Первую игровую проверку проводить на копии мира; существующие структуры не перестраиваются.
