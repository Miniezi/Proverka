# MINI additions 1.4.0 — неофициальный порт на NeoForge 1.21.1
Оригинал: Minigato668, https://modrinth.com/project/qHl9EvT8, MIT.
Исходный релиз закреплён URL и SHA-512 в upstream.json.

Статус: неофициальная тестовая версия (RC1). Результаты серверной проверки — в VALIDATION_RU.md рядом с JAR. Клиентская игра и полная сборка пока не проверены.
Зависимости: Minecraft 1.21.1, NeoForge 21.1.256, Spore 2.2.0j.
Установка готового JAR в mods. Старый Forge-JAR и Spore Inquisition одновременно не устанавливать.
Create не требуется. Встроенные конфиги Spore из версии 1.20.1 не переносятся поверх конфигов сборки.

Перенос: пути ресурсов 1.21, компоненты предметов, зачарования, атрибуты NeoForge,
рецепты, достижения, NBT предметов призываемых мобов, проверки предметов в руках.
Структуры сохраняют исходный DataVersion для штатного Minecraft DataFixer; NBT модовых защитников (эффекты, экипировка и модификаторы атрибутов) перенесён отдельно.
Команды Wither Storm вызываются лениво, только при наличии его сущностей. Интеграции Wither Storm и Touhou Little Maid не требуют установки этих модов.
Совместимость Farmer's Delight рассчитана на 1.3.4 для NeoForge 1.21.1.
Рецепты Create обновлены под 6.x, но совместимость Create, Incendium, Better Combat, Wither Storm и Touhou Little Maid в игре не проверялась. Эти моды не обязательны.

В оригинале ледяной заряд обрабатывает огромную область и может надолго заморозить сервер.
Эта механика требует отдельной оптимизации; не применять в ценном мире без резервной копии.

Сборка: Python 3 + nbtlib==2.0.4; python port.py.
В harness находится отдельный тестовый мод, который НЕ включается в выдаваемый JAR.
